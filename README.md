# ⚡ VS Code-Style Online Python Compiler & IDE

A fully functional, browser-based Python 3 IDE styled after **Visual Studio Code**, powered by WebAssembly (**Pyodide**) and Microsoft's **Monaco Editor** engine. 

No backend servers, no API keys, and 100% free to host statically on **GitHub Pages**.

## 🌟 Features

* **Authentic VS Code UI (Dark+ Theme)**: Features a left activity bar, file explorer sidebar, top title bar, tab bar, integrated terminal pane, and status bar.
* **Monaco Editor Core**: Uses the exact same code editor engine that powers VS Code, offering precise syntax highlighting, dark mode themes, a minimap, and smooth scrolling.
* **Client-Side Execution (Pyodide)**: Runs Python entirely inside your browser via WebAssembly at native speeds without needing a remote server.
* **Integrated Terminal**: Automatically captures standard `print()` output, standard errors, and Python runtime exceptions in a styled terminal console.
